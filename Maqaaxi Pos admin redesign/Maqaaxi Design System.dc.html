v1 · light

One neutral, slightly warm base carries the data. Goodir maroon is reserved for identity, primary actions and the active state — never for status. Status colour is a separate, four-hue channel so a red row always means something is wrong, not something is branded.

One ink floor: #6E6E68 is the lightest colour text may use on white cards (5.2:1) or the page canvas (4.7:1). On the tinted grounds — #EFEFEA chips and the #F6E8EC selected row — go one step darker to #57574F (5.7:1 and 6.1:1). White text never sits on warning amber #B06A00 (4.3:1) — solid amber fills use #8A5300. #9A9A93 and lighter are for rules, icon strokes and disabled glyphs only, never for reading.

05 · Status vocabulary

Two axes, as the data has them: order status and payment status — labels exactly as orderUi.jsx defines them
Awaiting Order status pending — an online order waiting to be accepted or declined. Pulsing dot, counts into the Orders badge.
In kitchen Order status open — accepted and cooking. Shows table number, time open and a Take payment action while it is unpaid.
Paid Payment status paid — settled. Recedes visually: no left-rule emphasis, muted row.
Stuck payment An online payment with no order attached. Always sorted to the top with a reconcile action.
Voided Order status voided — struck-through chip, greyed row, reason in the detail panel.
Declined Order status declined. Refunded and On account are payment chips on the same row.
